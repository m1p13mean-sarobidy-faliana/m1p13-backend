- Connexion (Admin, Buyer, Shop)
- Déconnexion
- Voir/Modifier mon profil

## 2. ADMIN - Gestion Centre Commercial

- Voir toutes les boutiques (actives, en attente, suspendues)
- Approuver une boutique en attente
- Suspendre une boutique
- Créer/Modifier/Supprimer une catégorie
- Tableau de bord (stats simples : nb boutiques, nb acheteurs, nb produits)

- Voir/Modifier mon profil boutique (nom, description, catégorie, horaires)

- Modifier/Supprimer mes produits

- Créer une promotion sur un produit (% réduction, période)
- Voir les avis reçus sur ma boutique

## 3. ACHETEUR - Navigation & Interaction

- Voir toutes les boutiques
- Filtrer boutiques par catégorie

- Voir le détail d'une boutique (infos + produits)
- Voir tous les produits du centre
- Rechercher/Filtrer produits (par nom, catégorie, prix)
- Voir les promotions actives
- Ajouter/Retirer une boutique de mes favoris
- Noter et commenter une boutique (1-5 étoiles)
- Voir mes favoris
